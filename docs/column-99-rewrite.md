# 99장 칼럼 다시 쓴 것 — 관리자 화면에 붙여 넣을 값

D1 `insights` 는 관리자 세션이 있어야 고칠 수 있어 파일로 둔다.
관리자 → 칼럼 → 99장 에서 아래 값으로 바꾸면 된다.

고친 이유는 `CLAUDE.md` 의 "쉬운 말" 과 "칼럼 기준" 에 적혀 있다. 요약하면
세 가지다.

1. 글의 척추가 "오컴은 그 말을 안 했다" 였다. 읽고 나면 "속았구나" 만 남는다
2. 원문 2절이 이미 말한 것(14세기·17세기·라틴어 문장)을 더 자세히 되풀이했다
3. 결론이 추상으로만 되어 있었다 — "앞쪽은 세상에 관한 주장이고, 뒤쪽은
   논증하는 방법에 관한 규칙이다"

---

## title

```
간단해서 맞는 것이 아니다
```

(전: `오컴은 면도날을 들지 않았다` — 제목이 바로잡기를 예고하고 있었다)

## hook

```
"간단한 쪽이 맞겠지"와 "근거 없는 건 빼자"는 전혀 다른 말이다.
```

(전: `그 이름이 붙은 문장도, 면도날이라는 말도 그의 것이 아니다.`)

## quotable

```
간단한 설명이 맞다는 보장은 없다. 다만 근거를 덜어 낸 설명은 틀렸을 때 빨리 들킨다
```

(전: `단순함은 진리의 증거가 아니라, 근거가 없는 것을 덜어 내라는 규칙이었다`)

## action

```
지금 붙들고 있는 설명 하나를 떠올려 보세요.
그 설명에서 확인할 수 있는 것은 무엇이고, 그냥 끌어다 붙인 것은 무엇입니까?
```

## body_md

```markdown
매출이 떨어졌다. 한 사람은 경기가 나빠서라고 하고, 다른 사람은 지난달 올린 배송비 때문이라고 한다.

회의에서 흔히 나오는 말이 있다. "간단한 쪽이 맞지 않겠어요?"

이 말에는 숨은 가정이 있다. 세상이 간단하게 생겼다는 것, 그래서 간단한 설명이 더 자주 맞으리라는 것이다.

오컴은 그렇게 말한 적이 없다.

그가 적은 것은 "필요 없이 여럿을 놓지 말라"였다. 근거 없이 끌어온 것은 빼라는 뜻이다. 간단한 쪽이 맞다는 말이 아니다.

쓰인 자리를 보면 뜻이 분명해진다. 조용한 서재가 아니었다. 그는 이단 혐의로 교황청에 불려가 아비뇽에 몇 해 묶였고, 밤에 달아나 황제에게 몸을 맡겼으며, 파문된 채로 죽었다. 면도날은 상대가 근거 없이 끌어온 개념을 쳐내는 무기였다.

그러니 두 말은 전혀 다르다.

"간단한 설명이 맞을 것이다"는 세상이 어떻게 생겼는지를 주장한다. 증명할 길이 없다.

"근거 없는 것은 빼라"는 내 설명을 어떻게 손볼지 알려 준다. 지금 당장 할 수 있다.

앞의 매출로 돌아가 보자. 경기는 간단하지만 확인할 것이 없다. 배송비는 올린 날짜가 있고, 그 전후의 주문 수가 있다. 맞춰 보면 하루 만에 갈린다.

간단한 설명이 맞다는 보장은 없다. 다만 근거를 덜어 낸 설명은 틀렸을 때 빨리 들킨다. 끌어다 붙인 것이 적으니 어디가 어긋났는지 금방 보인다.

그래서 물어볼 것은 "어느 쪽이 간단한가"가 아니다. **"이 설명에서 내가 근거 없이 끌어온 것은 무엇인가"**다.

"진리는 단순하다"는 이 책의 마지막 문장이다. 아흔아홉 개를 지나온 사람은 알게 된다. 짧고 분명해 보이는 말일수록 뒤에 붙은 사연이 길었다는 것을.

빼는 일은 간단하지 않다.
```

### 카드를 다시 구울 것

`quotable` 과 `anchor_quote` 가 카드에 들어간다. 칼럼을 저장한 뒤:

```
python tools/make_og.py ockham-never-said-razor
```

슬러그를 바꾸려면 카드 파일 이름도 함께 바뀐다. 이미 나간 메일과 공유
링크가 옛 슬러그를 가리키므로 **슬러그는 그대로 두는 편이 낫다**.
